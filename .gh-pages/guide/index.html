# V2Ray 配置指南

欢迎来到 V2Ray 配置指南！本指南提供了详细的配置教程和实用案例。

  • 介绍V2Ray - 了解 V2Ray 的基本概念
  • Linux 安装 - 在 Linux 系统上安装 V2Ray
  • Windows 安装 - 在 Windows 系统上安装 V2Ray
  • 安卓安装 - 在安卓设备上安装 V2Ray
  • Docker 安装 - 使用 Docker 部署 V2Ray
  • v2ray 命令 - V2Ray 命令行工具使用

  • 禁用 BT - 禁用 BT 流量

  • 反向代理（端口映射） - 端口映射
  • 反向代理（IP 穿透） - IP 穿透配置
  • 运行多个服务端进程 - 多进程部署
  • 负载均衡（balancers） - 使用 balancers 实现负载均衡
  • 负载均衡（vnext） - 使用 vnext 实现负载均衡

# 💡 使用建议

  1. 新手入门：建议按照顺序从"介绍和安装"开始阅读
  2. 快速查找：使用顶部搜索框快速定位特定功能
  3. 深入学习：逐步从基础配置学习到高级功能
  4. 实践操作：边学边配置，在实践中加深理解
