一、基本配置

​ 要关闭防火墙，iptables有规则的话也要清空

[root@martlet121 ~]# systemctl stop firewalld.service #关闭防火墙

[root@martlet121 ~]# systemctl disable firewalld.service #禁止开机启动

Removed symlink /etc/systemd/system/multi-user.target.wants/firewalld.service.

Removed symlink /etc/systemd/system/dbus-org.fedoraproject.FirewallD1.service.

[root@martlet121 ~]# setenforce 0 #关闭SELinux

[root@martlet121 ~]# sed -i 's/SELINUX=enforcing/SELINUX=disabled/g' /etc/sysconfig/selinux #直接替换原文件内容中模式为关闭
