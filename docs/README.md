## 📖 快速开始

### 什么是 V2Ray？

V2Ray 是 Project V 下的一个工具，是一个与 Shadowsocks 类似的代理软件，但功能更加强大和灵活。

**核心特点：**
- 🛡️ **更完善的协议** - 使用自研的 VMess 协议，更难被检测
- ⚡ **更强大的性能** - 网络性能优异，具有更好的并发处理能力
- 🎯 **更丰富的功能** - mKCP、动态端口、路由、WebSocket、Mux 等

### 📚 指南结构

本指南分为以下几个部分：

1. **介绍和安装** - 了解 V2Ray 的基础概念，学习在各种平台上安装
2. **基础配置** - 掌握配置格式和基本的协议（VMess、Shadowsocks、DNS）
3. **TLS 和传输** - 学习如何使用 TLS 加密和各种传输方式
4. **高级协议** - 深入了解 Mux、mKCP、QUIC、TOR 等高级协议
5. **高级功能** - 掌握负载均衡、透明代理、反向代理等企业级功能

### 🚀 开始使用

1. 选择你的操作系统，阅读对应的安装指南
2. 了解配置文件的基本格式
3. 根据你的需求选择合适的协议和传输方式
4. 参考具体的配置案例进行配置
5. 逐步深入学习更高级的功能

### ⚠️ 前置要求

本指南的目标用户需要具备：
- Linux 基本操作知识（如果在服务器上使用）
- 了解基本的网络概念
- 能够使用文本编辑器编辑配置文件

### 💡 提示

- 使用左侧导航菜单快速定位你需要的内容
- 使用顶部搜索框搜索特定的功能或协议
- 配置前建议先理解基本概念和配置格式
